# Figure grammar

A scientific diagram can explain a sequence by assigning each stage a distinct visual plane, maintaining consistent direction, and making related elements easy to trace. Plan the reading order before assigning motion.

- **Hierarchy:** reserve the strongest contrast for the current object of attention; use quieter supporting notes and a concise caption.
- **Layers:** separate transformations spatially and use restrained depth only when it clarifies their order. Overlap must not conceal connections.
- **Color and shape:** assign each accent a stable semantic role; combine color with labels or shape so meaning survives grayscale.
- **Annotation:** connect short explanations to their subject with clear leaders. Keep evidence and qualifiers next to the relevant step.
- **Data:** use small visual summaries only when they encode an actual quantity; do not fabricate numbers for texture.
- **Motion:** reveal the relation before advancing to the next stage. A moving marker can clarify direction, while a static end state and prose preserve the explanation without motion.
