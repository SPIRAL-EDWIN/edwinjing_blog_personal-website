## Scope and limitations

- The collection names Robotics, Philosophy and Chemistry are inferred from `Embodied AI`, `PHIL` and `CHEM`; other directory names are preserved or lightly normalized. Counts exclude notes explicitly marked `archive: false`; dates prefer authored `updated`, then Git history, authored date, then file modification time. Generated collection pages and their 21 note links were checked. Chinese and English were verified in note bodies.
- The desktop hero video is capped at 280px wide to meet the requested alignment and spacing; this is a visual tradeoff.
- P0-3: forward-only and play-once behavior, landmark compensation, independent figures, End, anchor navigation, repeat scrolling and hard reload were exercised in Edge. A simulated `document$` content replacement preserves state, but actual tested site clicks performed full-document navigation; real Material instant navigation is **not verified**. Session persistence configuration and mobile/reduced-motion edge cases beyond the prior run remain **not verified**.
- Performance comparison uses local unthrottled Edge at 1440×900, five fresh contexts, with intro and external requests disabled. Baseline built from archived commit may lack Git-history metadata. The current sample was captured before the last anchor/End handling adjustment. These are not field measurements and cannot establish statistical significance.
