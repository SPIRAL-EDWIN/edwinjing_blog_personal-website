Continuous touch, WebKit, all animation timing and exact connector anchors at every intermediate resize remain not verified.
- P0-4: `docs/refs/edwinos-date.md` describes live HTML/CSS reconstructed in Playwright with local fonts and measured light/dark styles. Direct external browser loading timed out. The academic news reference is MM/YYYY; its linked Archive uses a different format. Mobile blog rows stack intentionally.
