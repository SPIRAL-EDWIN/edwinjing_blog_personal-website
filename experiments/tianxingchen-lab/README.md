# 陈天行网页 · 机制学习示例

这个独立静态页面用于学习个人网页的实现机制：固定导航的五层渐进模糊、响应式双列布局、原生 `details`、八条 News 折叠、移动菜单和滚动章节选择。它使用原创示例内容与 CSS 插画，不是原站镜像，也不包含原站的个人信息、照片、外部字体或追踪脚本。

参考 [实际网页](https://tianxingchen.github.io/) 与 [固定提交的 index.html](https://github.com/TianxingChen/tianxingchen.github.io/blob/b92ce6cd97835ce5a63028a37b0edc27eef02cfd/index.html)，提交 `b92ce6cd97835ce5a63028a37b0edc27eef02cfd`。实现依据导航渐进模糊、响应式布局及页面交互的研究记录；本实验重新编写 HTML/CSS/JS，便于隔离观察。

在仓库根目录运行：

```sh
python3 -m http.server 8001 --bind 127.0.0.1 --directory experiments/tianxingchen-lab
```

打开 [本地学习示例](http://127.0.0.1:8001/)。没有安装步骤或构建依赖。`index.html` 负责内容，`lab.css` 负责独立样式，`lab.js` 负责必要的状态交互；这些文件不进入 EdwinOS 的生产 CSS/JS。

浏览器可以按以下顺序体验：

1. 在 1440、768、390px 窗口检查导航高度、容器宽度和插画顺序。
2. 把彩色样本滚到顶部导航后方，观察逐渐淡出的模糊。
3. 展开原生说明，再展开 News 的剩余四条记录。
4. 小屏打开导航，按 Escape 检查关闭与焦点恢复。
5. 点击章节、滚到文档底部，观察选中下划线。
6. 禁用 JavaScript，或启用系统的“减少动态效果”，检查阅读与交互降级。

有意加入的学习版改进：

- News 按钮维护 `aria-expanded` 和 `aria-controls`；所有 12 条记录预先写在 HTML，关闭脚本会全部显示。
- 菜单按钮同步可访问名称与展开状态，Escape 关闭后恢复按钮焦点。
- 不拦截原生锚点、历史记录和链接行为；滚动测量通过 `requestAnimationFrame` 合并。
- 入场效果只在观察器可用后启用，内容默认可读；减少动态效果关闭入场和顺滑滚动。
- 使用系统字体回退和本地 CSS 插画，没有外部资源加载、动画循环或后端请求。原站与源码链接仅在读者主动访问时跳转。

渐进模糊需要浏览器支持 `backdrop-filter` 和遮罩。未支持时白色渐变仍保证导航可读，精确光学效果可能因浏览器而异。本例刻意不实现原站的图库、完整履历或其它更大组件。
