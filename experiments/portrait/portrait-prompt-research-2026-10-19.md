# 个人网页肖像：身份保持与自然摄影、彩铅、油彩 Prompt 调研

调研日期：2026-10-19。目标是用本人自拍制作自然、清爽、有环境美感的网页肖像，也接受克制的彩铅或油彩，但本人必须仍可辨识。本轮核对原始 skill、prompt 文件与官方图像编辑文档，没有安装新 skill、上传自拍、运行第三方脚本、生成图片或更改网站。

## 推荐结论

南鸢 `nuyoah-xiezhen-prompt` 能帮助拆解摄影参考、设计自然光、人物姿态和环境层次。对本任务最值得借用的是“身份参考与风格参考分工”以及避免模型过度商业精修的规则。它本身是提示词与工作流，最终相似度依赖实际输入照片和图像编辑模型；没有自拍样张实测，不能保证效果。

建议组合使用：南鸢的摄影方案结构 + lovstudio 的身份保持约束 + 根据实际自拍编写的场景/媒介要求。先比较自然摄影、细彩铅、薄涂油彩三个方向。推荐优先试自然摄影；这是针对当前参考图的审美判断，不是模型效果排名。

## 参考图的可见特征与设计推导

用户提供的参考图是一张接近方形的冰雪环境半身肖像。人物正面看镜头，姿态较放松；深色外套与浅色围巾形成清楚轮廓，背景以冰川形态和较大浅色区域为主，整体有明显蓝青色倾向。画面没有强烈硬阴影，呈柔和环境光效果；仅凭图不能确定实际天气、器材或后期过程。

值得借用的：真实自然环境、放松的身体语言、面部可辨识、环境形成大色块而不抢主体。个人网页版本可以适度拉近景别，使缩小显示时仍看清脸；保留清爽背景色，肤色可比参考图更中性。并不需要固定复制冰川、围巾、相机或原人物长相。

轻绘画版本的建议：让背景和衣物承担更多笔触，脸部保留完整结构与主要细节。彩铅选择细密叠色、干净纸面；油彩选择薄涂、克制色块与较准确的脸部塑造。以上是设计提案，需真人参考生成后验证。

## 生图能力与 prompt 的关系

生成本人肖像时，应使用支持照片输入的图像编辑/参考生成入口。纯文字写“像我本人”无法向模型提供你的外貌。提示词应说明引用哪张照片，而不是先用文字重新想象一张脸。

可考虑的实际路径：

- GPT Image：官方 [图像提示指南](https://developers.openai.com/api/docs/guides/image-prompting)展示保持身份、变更服装、转移风格和新场景的提示模式。具体可用模型和入口以实际环境为准。
- Gemini / Nano Banana：官方 [图像生成文档](https://ai.google.dev/gemini-api/docs/image-generation)提供多参考图片与风格迁移方法。要明确自拍与风格图分工。
- Qwen：官方 [Qwen-Image-2.1](https://github.com/QwenLM/Qwen-Image-2.1)声明支持多参考图和人物身份保持；它是模型路线，不是 prompt skill。在线使用与自行部署的工作量不同，未在本机运行。

本次没有核价、运行或对比这些路线；不宣称其中任何一个能一次保留全部五官。PhotoMaker / InstantID 等身份条件模型可供更深入的技术方案研究，但不是完成一张网页肖像的必需步骤。

## 自拍选择与参考职责

建议先准备 3 张同一时期、未经明显美颜处理的清楚照片：一张平视正面作为主要身份来源，一张轻侧角补充结构，一张表情与本人日常状态接近。数量是操作建议，不是所有模型的固定要求；实际受入口图片数量限制。

优先选自然光、脸无遮挡、没有贴脸广角畸变的原图；自拍距离太近或滤镜改变五官时，模型会继承这些偏差。尽量保留平时佩戴的眼镜与真实发型。可以轻微清理临时痘印，但不要统一删掉痣、自然不对称或改小鼻子、改尖下颌。

以下模板约定：图 1 为主要本人自拍，图 2、图 3 为同一人的辅助照片，图 4 为用户提供的学长照片。只有图 1—3 提供身份；图 4 仅提供摄影气氛。若实际图片数量不同，先改编号和职责，避免空引用。

## 可直接使用的 Prompt

以下为按本任务自行编写的中文提示词，综合了上面的方法，但不是任何仓库的原文，也没有经过生图验证。每个版本单独生成一张图，不要要求模型把三个媒介混在一张图里。不要把中文的“风格强度百分比”当成模型有保证的控制参数。

### A：雪山夕阳自然肖像版（含身体比例约束）

```text
请为我的个人网站制作一张雪山夕阳中的自然肖像，清爽、温暖、放松，兼具真实的个人气质与自然环境的美感。

【参考职责与本人身份】
图1是本人的主要身份参考，图2和图3是同一人的辅助身份参考。输出必须是这些自拍中的本人。图4只参考自然环境中的松弛感与人与风景的关系；本次背景、服装、发型整理与光线服从下述新方案，不照搬图4人物的长相或整张照片的蓝色色偏。
保留本人真实的面部结构、五官比例、自然不对称、年龄感、肤色与辨识特征；如自拍中佩戴眼镜，保留相同形制。本人辨识度优先于理想化美颜。
如另有本人原始半身或全身照片，以该照片作为体型与身体比例的主要依据。此前生成失败的湖边样张只用于诊断比例问题，不提供本人身份或身体结构。

【身体比例：与面部身份同等优先】
保留本人原始身体参考中的头部大小、肩峰间距、肩斜、颈长、胸腔宽度和肩至腰的长度关系，保持自然体格，不额外增肌、拉宽肩膀或修长躯干。不套用统一的模特肩头比、头身比，也不从宽松衣服的外轮廓反推骨骼宽度。
头部、颈部、肩带、胸腔与躯干必须属于同一个连续人体，转角与透视一致；不能把真实头部像贴图一样接到另一副身材上。不要通过缩头、放大头、拉长脖子、耸肩或压短上身来调整构图。

【构图与人物状态】
方形半身构图，取景从头顶到腰部附近，完整保留头发、颈部、双肩和自然长度的上身。相机平视并保持足够拍摄距离，采用自然的人像透视，避免贴脸自拍式广角和明显俯拍。先建立完整可信的人体比例，再统一缩放人物放入画面；画面放不下时拉远取景，不压缩躯干或改变肩宽。头顶与两侧适量留白，不用过多天空挤占躯干空间。
人物站在雪山观景处，身体微侧，脸自然转向镜头，肩颈放松，上臂沿身体自然下垂，双手位于画面下方。像旅途中被朋友叫住拍下的瞬间，眼神专注而亲近，嘴角轻微上扬，表情自然。

【雪地穿搭】
将自拍中的日常上衣更换为深海军蓝保暖滑雪外套，哑光防风面料，少量浅灰拼接，内搭米白色保暖中层。选择正常合身、适度保暖的剪裁，肩缝跟随真实肩峰；衣物厚度合理增加外轮廓，不改变底下的骨骼宽度、颈部位置与躯干长度。避免垫肩、超宽落肩、球状膨胀的羽绒肩部，以及从领口向下不合理外扩的衣身。保留接缝与自然褶皱，帽兜放下，领口保暖但不遮下颌；面部与发型完整可见，不添加头盔、雪镜或醒目品牌标志。

【发型整理】
保留真实发际线、发色与原有长度，在自拍发型基础上整理得更利落、有自然蓬松度和清楚的发束层次。面部周围的头发适度理顺，少量发丝被微风轻轻带动，不遮眼睛，不做僵硬定型或夸张增发。

【雪山与夕阳】
背景是层次清楚的积雪山峰、开阔雪坡和低处山谷。远山仍能辨认山脊与雪面纹理，细节适度柔化。夕阳位于画面左后方的远山附近，部分被山脊遮挡；受光山峰呈浅金与淡桃色，背光雪面保留清淡蓝灰，天空由浅杏色自然过渡到淡蓝，环境开阔、干净。

【光线与成像】
低角度夕阳从画面左后方照来，只在同侧发梢、肩部与外套边缘形成细而柔和的暖色亮边。人物正面由开阔天空与雪地反射光柔和提亮，眼窝、眼睛和嘴角清楚，脸部明暗有层次，肤色自然，只带少量暖意。暖色夕照与冷色雪影保持克制平衡，雪面高光保留纹理，深色外套仍有细节。
眼睛与主要五官对焦准确，景深适中，背景可读，保留真实皮肤、发丝与衣料质感。整体明亮通透，像实际旅途中拍到的一张好照片。

不要瘦脸、放大眼睛、改变鼻梁或下颌；不要大头窄肩、小头宽肩、颈部拉长、左右肩结构失衡、躯干压短或拉长、肩颈拼接感。不要塑料皮肤、全脸橙黄、过度饱和的橙蓝调色、剪影式暗脸、整圈发光光晕、大面积眩光或夸张散景。不要文字、水印或额外道具。
```

比例核对说明：失败样张中的宽松落肩上衣与胸像裁切会干扰身体比例判断，不能据此确认本人的真实肩宽或身长。若只有脸部自拍，提示词只能约束自然人体关系，不能精确还原未显示的躯干与身高。优先补一张未经生成、拍摄距离适中、能看到肩部至腰部的本人原始照片。此次不设固定的肩头比数值。

### B：清爽细彩铅版

```text
请根据图1中的本人制作一张用于个人网站的彩铅肖像。图2、图3只补充同一个人的真实面部结构。图4仅参考自然环境、放松姿态与清爽气氛，不继承其中人物的面部特征。

必须让熟悉本人的人能够认出我。保留自拍中的面部结构、五官比例、年龄感、发际线、真实肤色关系和辨识特征，不做卡通式大眼、尖下巴或美颜重塑。表情安静亲近，嘴角轻微放松，眼睛自然看向观众。

方形胸像，平视，肩颈舒展，头发和双肩完整。人物穿浅灰蓝色休闲上衣，背景为湖岸和远处山形。采用干净的象牙白纸面、细密而轻柔的彩铅叠色、可见但克制的纸纹，浅蓝和鼠尾草绿配自然暖肤色。

脸部结构画得完整准确，眼睛、鼻翼和嘴角边界清楚，头发有方向明确的细线。背景和衣物适当简化，背景笔触比面部更松，留白干净但不能让人物缩成小点。整体柔和、明亮、有手绘温度。

不要抽象化五官，不要幼态化、漫画化、粗黑描边、脏乱排线或厚重纸面噪点。不要文字、水印和装饰边框。
```

### C：干净薄涂油彩版

```text
请以图1中的本人为主体，结合图2、图3所显示的同一人真实外貌，创作一张可辨识的油彩个人肖像。图4仅供自然环境、平视半身感与放松气质参考，不提供人物身份。

优先保留本人的真实面部结构、五官关系、年龄感、发际线、自然不对称与辨识特征，不把人物理想化成另一个人。脸部转角很小，眼神自然看向观众，嘴角放松，肩颈舒展。方形构图，胸部以上偏近景，头发和双肩完整。

人物穿简洁的浅灰蓝色休闲上衣，置于开阔湖岸与远山前。柔和散射日光，清淡的灰蓝、绿与暖肤色相互协调。采用薄涂油彩，干净的明暗色块、少量清楚的笔触和轻微画布纹理。

面部塑造比衣物和背景精确，眼鼻嘴结构与自拍一致；衣物、植物和远山以更松的笔触概括，边缘柔和但不将脸融进背景。画面轻盈、明亮、安静，有可见的绘画质感，同时保留本人样貌。

不要厚重堆砌颜料、强烈旋涡、破碎五官、夸张透视、戏剧暗部或抽象色块覆盖脸部。不要文字、水印或签名。
```

## 生成后的判断方式

1. 先比较原始自拍与成片：脸型、眼鼻嘴关系、发际线、痣/眼镜等特征是否变了。画得漂亮不能替代“像本人”。
2. 用同一组自拍分别试三种风格，先让自己判断最像哪张，再评审色彩与环境。若绘画版失去辨识度，先减小脸部的笔触概括，保留背景的绘画感。
3. 将候选图缩到网页实际显示尺寸；如果环境好看但脸太小，应拉近景别，而非继续提高背景细节。正式使用前再核对网页裁切。
4. 每次重做都保留原始自拍作为身份依据。明确编辑已选成片时，可以将成片作为编辑目标，并继续引用原始自拍核对身份；不能只用多轮生成图循环推演而不检查本人样貌。

真正的效果、模型选择和最终风格，等待本人自拍生成对比后再确定。
